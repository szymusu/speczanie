Praca obejmuje stworzenie aplikacji komputerowej do graficznej analizy pomiarów z prób spęczania.
Aplikacja jest natywnym programem możliwym do skompilowania na komputery z systemem Windows, Linux i macOS w wersji 32 lub 64 bitowej.
Została stworzona w języku C z wykorzystaniem biblioteki Raylib, co zapewniło wysoką wydajność i płynność działania.
Główną funkcją aplikacji jest wyświetlanie i obróbka wykresów, obejmująca takie operacje jak: przesuwanie, odwracanie, ucinanie, ekstrapolacja prostej oraz regresja wielomianowa.
Dane do programu wczytywane są z plików tekstowych w formacie CSV oraz plików binarnych generowanych przez oprogramowanie maszyny pomiarowej w formacie W01.
Program posiada funkcję eksportu obrobionego wykresu do pliku CSV, aby zachować postęp, oraz umożliwia otwieranie wielu plików jednocześnie.
Posiadając wiele pomiarów z próbek o tych samych wymiarach oraz podaniu tychże wymiarów, aplikacja może przeliczyć wykresy siły w funkcji przemieszczenia na wykresy naprężenia w funkcji odkształcenia, wyświetlając je jednocześnie dla wszystkich otwartych plików.
Pozwala to na szybkie porównanie własności tych próbek w różnych warunkach.

Praca opisuje techniczne aspekty aplikacji takie jak: ogólna architektura, wybrane szczegóły implementacjyjne oraz proces optymalizacji wydajności jednego z krytycznych algorytmów.
Praca zawiera również instrukcję obsługi i opis zasady działania głównych funkcjonalności oraz trzy przykłady praktycznego zastosowania na prawdziwych danych.


This thesis covers creation of a desktop application for graphical analysis of the results of compression tests.
The application is a native program able to be compiled for computers with Windows, Linux and macOS operating systems in a 32 or 64 bit version.
Use of the C programming language and using the Raylib library resulted in high performance and no visual delay.
The main feature of the application is displaying and modifying plots with operations such as: translation, flipping coordinates, cutting, line extrapolation and polynomial regression.
The point data for the program can be read from a CSV text file or a custom binary W01 file format generated by the compression test machine's software.
The program can also export the current modified data points to a CSV file for later use and supports opening multiple files at simultaniously.
After importing multiple result files of samples with identical dimentions and providing those dimentions, the application can convert the load-stroke plots to tension-deformation plots and display them simultaniously on the same grid.
This feature helps quickli compare properties of these samples in different condition.

The thesis describes technical aspects if the application like: general architecture, selected implementation details and the process of performance optimization of one critical algorithm.
The thesis also contains a user's manual and principles of operation of the main application's features, as well as three practical usage examples with real data.
